# LFIguard: Валидация путей в Python

*Читать на других языках: [English](README.md).*

## Что это такое?
**LFIguard** — это простая Python библиотека, которая не дает украсть ваши файлы через атаки Path Traversal и Local File Inclusion. Она удерживает все пути внутри одной главной папки. Если пользователь попытается использовать обходы вроде `../` чтобы выбраться наружу, библиотека автоматически заблокирует его и защитит систему.

## Что умеет LFIguard
- **Двойная защита:** Использует сигнатурный анализ регулярными выражениями (блокирует URL-encoding и Unicode-обходы), проверяет границы папок на уровне ОС.
- **Защита от падений:** Безопасно обрабатывает некорректный ввод (слишком длинные строки, запрещенные символы).
- **Строгая очистка путей:** Разворачивает любые относительные переходы (`.` и `..`), вычисляя реальный конечный адрес файла.
- **Без сторонних зависимостей:** Чистое решение на Python, использующее только встроенные модули.

## Зависимости
- **Python 3.10+**
- Сторонние пакеты не требуются. Библиотека использует только стандартные модули (`os`, `re`, `pathlib`, `unittest`).

## Установка
1. Клонируйте репозиторий:
```bash
git clone https://github.com/splYozik/LFIguard.git
```
2. Перейдите в папку, установите локально через `pip`:
```bash
cd LFIguard
pip install .
```

## Примеры кода
```python
from path_guard.protector import SafePathGuard

# 1. Указываем папку, из которой пользователю ЗАПРЕЩЕНО выходить
guard = SafePathGuard("/var/www/app/uploads")

# 2. Тест ввода пользователя
user_input = "avatar.png"
if guard.is_safe_path(user_input):
    print("Файл безопасен, можно открывать!")
else:
    print("Обнаружена атака! Доступ заблокирован!")
```
